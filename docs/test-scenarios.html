수동 테스트 시나리오

브라우저로 직접 따라 해 보는 기능별 확인 목록입니다. 결과(통과/실패)와 메모는 이 브라우저에만 저장됩니다.

시작 전 준비

내 PC에서 Cloudflare Worker를 띄워 시험합니다(Node.js 22 이상). 처음 한 번은 apps/edge/README.md의 로컬 개발대로 .dev.vars를 만듭니다.

  1. 깨끗한 상태에서 시작하려면 로컬 D1·R2를 지우고 스키마를 다시 적용합니다. 로컬에 넣은 작품과 파일이 모두 지워집니다. 운영 데이터에는 영향이 없습니다.
    cd apps/edge && rm -rf .wrangler && npm ci && npm run db:migrate:local && npm run build:web
  2. 서버를 띄웁니다. 끄지 말고 다른 터미널에서 나머지 명령을 실행합니다.
    cd apps/edge && npm run dev
  3. 접속 주소: http://localhost:8787
  4. A 그룹(첫 설정)을 먼저 하고, C 그룹은 C1로 샘플 작품을 넣은 뒤 진행합니다.
