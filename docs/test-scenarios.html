수동 테스트 시나리오

브라우저로 직접 따라 해 보는 기능별 확인 목록입니다. 결과(통과/실패)와 메모는 이 브라우저에만 저장됩니다.

시작 전 준비

  1. 깨끗한 상태에서 시작하려면 볼륨까지 지우고 다시 띄웁니다. DB와 업로드 파일이 모두 지워집니다.
    docker compose down -v && docker compose up -d --build
  2. 컨테이너가 모두 떴는지 확인합니다. api가 healthy가 될 때까지 기다립니다.
    docker compose ps
  3. 접속 주소: http://localhost:8080 · API 문서: /api/v1/docs
  4. A 그룹(첫 설정)을 먼저 하고, C 그룹부터는 데모 데이터를 넣은 뒤 진행합니다.
